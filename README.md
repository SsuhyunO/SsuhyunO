### 📈 [GA-TA-ESN-Model](https://github.com/SsuhyunO/GA-TA-ESN-Model)

기술적 지표와 Echo State Network를 결합해 주식 매매 신호를 예측하는 캡스톤 프로젝트입니다.

- **기술:** Python, pandas, NumPy, TA-Lib, DEAP, scikit-learn, Backtesting.py
- **핵심 구조:** CPM 변곡점 추출 → GA 기반 MA·RSI·ROC 최적화 → ESN 매매 신호 생성
- **검증:** Train/Validation/Test를 분리한 Expanding Window 롤링 포워드 백테스트
- **개선 경험:** 라이브러리 호환성, multiprocessing, 자료형 오류 및 실험 재현성 보완
- **현재 작업:** 폴드별 수익률·Buy & Hold·MDD 결과 정리 및 공개용 보고서 작성
